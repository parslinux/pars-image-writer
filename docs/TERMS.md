## 1. Nature of the Software and Destructive Write Warning

Pars Image Writer is an advanced disk imaging utility designed to write operating system installation images (`.iso`, `.img`) directly to removable block devices (USB flash drives).

**CRITICAL WARNING:** Disk writing operations are inherently destructive to data stored on the target storage device. All partitions, filesystems, and data previously residing on the selected target disk will be irreversibly erased and overwritten during the write process.
